# SPARK!E 董事长模拟(原型 v0.1)

一个人经营数字艺术工作室 SPARK!E 的一年(2027 年四个季度)。
界面参考 90 年代 PC-98 文字冒险,规则全部由代码计算,没有接任何 API。

## 运行
双击 `public/index.html`,或进入 `public/` 执行 `python3 -m http.server`,再访问 http://localhost:8000 。

## 玩法
- 每季度先遇到一件事(做选择),再用 10 到 12 个时间点安排:接商单、做自己的作品、投展览/基金。
- 点对话框或按空格继续,按 1 到 4 选择选项。进度在每个季度的安排阶段自动保存。
- 难度:轻松(现金不会见底,没有个人担保)/ 真实(会动用个人安全垫,贷款需个人担保并计利息,客户可能拖款)。
- 目标:一年内现金 ≥ ¥40,000、声誉 ≥ 15、作品 ≥ 4,解锁下一条业务线 F'est Vie(下一版开放)。

## 文件
- `public/index.html` 页面结构
- `public/style.css` 像素风样式
- `public/game.js` 规则、事件、场景和头像的像素绘制
- `wrangler.jsonc` Cloudflare 部署配置,指向 `public/`
